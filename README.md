## 📌 Project Overview

This project was completed as part of the **Deloitte Australia Data Analytics Forage case study simulation**.

The project focuses on analyzing factory telemetry data from Daikibo manufacturing facilities to identify operational patterns and support data-driven decision-making.

The analysis involved understanding the dataset structure, validating data quality, preparing the data for analysis, and creating visualizations to communicate operational insights.

> **Note:** This is a Forage case-study simulation and does not represent consulting work performed for Deloitte or Daikibo.

---

## 🎯 Business Objective

The objective was to analyze factory telemetry data and transform operational data into useful business insights.

The analysis focused on:

- Understanding factory and machine telemetry
- Identifying operational patterns
- Comparing factory performance
- Analyzing machine/device activity
- Creating clear visualizations for decision-making

---

## 📊 Dataset Overview

The dataset contained approximately **160,704 telemetry records**.

Key fields included:

- Document Index
- Status
- Temperature
- Device ID
- Device Type
- Area
- City
- Country
- Factory
- Section
- Timestamp

The data represented telemetry information collected from manufacturing environments.

---

## 🧹 Data Preparation

The dataset was reviewed and prepared before visualization.

Key preparation activities included:

- Reviewing the dataset schema
- Selecting relevant fields
- Checking data types
- Reviewing telemetry values
- Preparing fields for analysis
- Organizing the data for Power BI visualization

Data preparation was important to ensure that the resulting charts represented the underlying factory data accurately.

---

## 📈 Power BI Analysis

Power BI was used to transform the prepared telemetry data into interactive visualizations.

The dashboard analysis focused on:

### Factory Analysis

Comparing telemetry activity across different Daikibo factories.

### Device Analysis

Examining activity across different device types.

### Operational Analysis

Analyzing machine status and telemetry patterns.

### Geographic Analysis

Comparing activity across cities and countries.

### Time Analysis

Using timestamp information to identify operational patterns over time.
