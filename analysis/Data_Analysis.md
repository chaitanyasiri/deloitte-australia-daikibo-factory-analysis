# Data Analysis

## Dataset

The Deloitte Australia Forage case study involved Daikibo factory telemetry data.

The dataset contained approximately 160,704 records and included fields such as:

- Device ID
- Device Type
- Status
- Temperature
- Area
- City
- Country
- Factory
- Section
- Timestamp

## Data Preparation

The dataset was reviewed and prepared for analysis before creating Power BI visualizations.

## Analysis

The analysis focused on:

- Factory activity
- Device activity
- Machine status
- Geographic patterns
- Time-based operational patterns

## Visualization

Power BI was used to create visualizations that made the large telemetry dataset easier to analyze and communicate.

## Business Value

The analysis demonstrates how manufacturing telemetry can support operational monitoring and data-driven decision-making.
