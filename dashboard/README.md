# Power BI Dashboard

The Power BI dashboard was created to analyze Daikibo factory telemetry data.

## Dashboard Analysis

The dashboard focuses on:

- Factory performance
- Device activity
- Machine status
- Geographic analysis
- Operational patterns

## Visualizations

The analysis includes Power BI charts designed to make factory telemetry easier to understand and compare.
